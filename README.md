# HEX HAVEN

모바일 브라우저용 육각형 퍼즐. 빈 칸 탭 → 60도 회전 → 배치. 보드 드래그로 이동합니다.

## 구조
- src/engine.js: 브라우저 의존성 없는 규칙, 덱, 별, 연결, 저장
- src/renderer.js: Canvas 타일 그리기
- src/main.js: 입력, 화면 조정, 저장과 UI 연결

기존 축 좌표 (q,r), E/NE/NW/W/SW/SE 변 순서와 타일 그리기를 유지합니다.
Unity에서는 직렬화된 board/deck 좌표, 지형 문자열 6개, special 플래그를 C# 데이터와 순수 함수로 대응시킬 수 있습니다.

## 규칙 정정
기존 코드의 점수 보너스와 120도 회전은 안내문과 달라 별 규칙과 60도 회전으로 정정했습니다.
맞닿은 같은 지형 변마다 별 1개, 특별 타일은 2개입니다. 배치하는 타일의 배수만 적용합니다.
특별 타일은 스테이지 2부터 매 5번째 타일입니다. 별 목표는 ceil(덱 크기 × 1.5)입니다.
스테이지 3부터 숲 5타일 연결도 필요합니다. 양쪽 숲 변이 맞닿은 타일 그래프의 최대 연결 요소이며 시작 타일도 포함합니다.
별 목표와 특별 타일 빈도는 초기 설정으로 플레이 기반 난이도 조정이 필요합니다.
시드 기반 덱은 두 지형 약 70%, 단일 지형 약 25%, 세 지형 약 5%이며, 두 지형은 4:2와 3:3 형태를 모두 사용합니다. 스테이지별 구성 수를 반올림하여 보장하고 순서를 섞습니다.

## 저장
점수에서 별로 단위가 바뀌어 버전 3과 hexhaven-save-v3 키를 사용합니다. 기존 hexhaven-save는 보존하지만 자동 변환하지 않습니다.

## 검증
Node.js 24에서 npm test 실행. 외부 패키지는 필요 없습니다. GitHub Actions에서도 실행합니다.
- test/engine.test.js: 6방향 별, 특별 타일, 연결/순환/분리, 복합 목표, 배치/승패/되돌리기, 회전, 덱 결정성, 저장 왕복
- test/ui.test.js: DOM/Canvas 대역으로 탭, 회전, 배치, 되돌리기, 드래그 취소, 보드 이동, 도움말, 재시작

실제 iPhone Safari 검증은 미완료입니다. 환경에 브라우저 바이너리가 없어 자동 브라우저 테스트를 실행하지 못했습니다.
기기에서 안전 영역, 주소창 크기 변화, 탭/드래그, 두 번째 손가락 무시, 제스처 취소와 별 미리보기를 확인해야 합니다.
