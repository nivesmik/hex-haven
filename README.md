# HEX HAVEN v0.7 실험

살아나는 강: 실제 물 변으로 강을 연결하고 강가 숲을 이어 수달을 찾아보는 퍼즐 실험입니다.
별 목표와 수달 목표를 모두 만족하면 Pass입니다. 등급·추가 발견 보상은 없습니다.
온대 하천 하나만 구현하며 생태 조건은 게임적 단순화입니다.

- 설정에서 편안함/기본/도전과 정수 시드를 선택합니다. 난이도 변경은 새 실험을 시작합니다.
- 다음 타일은 끌어놓지 않습니다. 빈 칸 탭 → 60도 회전 → 배치, 배경 드래그로 이동합니다.
- 일반 v0.6 진행은 설정에서 전환할 수 있으며 기존 저장을 유지합니다.
- 테스트 결과에서 사용 타일·별·재시작·undo·Pass/Fail을 확인하고 복사할 수 있습니다.
- `npm test`: 기존 회귀 테스트 + 생태계/저장/모드/UI/기록된 배치 경로 재생.
- `npm run simulate`: 고정 5시드×3모드 제한 탐색을 다시 실행해 fixture를 갱신합니다.
- src/ecosystem.js는 연결 질의·테마 데이터, src/experiment.js는 실험 설정·시드 셔플·자원 검사를 담당하며 브라우저에 의존하지 않습니다.

별·생태 목표와 특수 타일 수는 실험값입니다. 15조합 중 13개에서 Pass 경로를 찾았고 2개는 미검증입니다.
밸런스 확정이나 전체 시드의 클리어 가능성을 보장하지 않습니다. 실제 iPhone Safari 검증도 미완료입니다.

## 보존된 v0.6 안내


모바일 브라우저용 육각형 퍼즐. 빈 칸 탭 → 60도 회전 → 배치. 보드 드래그로 이동합니다.

## 구조
- src/engine.js: 브라우저 의존성 없는 규칙, 덱, 별, 연결, 저장
- src/renderer.js: Canvas 타일 그리기
- src/main.js: 입력, 화면 조정, 저장과 UI 연결

기존 축 좌표 (q,r), E/NE/NW/W/SW/SE 변 순서와 타일 그리기를 유지합니다.
Unity에서는 직렬화된 board/deck 좌표, 지형 문자열 6개, special 플래그를 C# 데이터와 순수 함수로 대응시킬 수 있습니다.

## 규칙 정정
기존 코드의 점수 보너스와 120도 회전은 안내문과 달라 별 규칙과 60도 회전으로 정정했습니다.
맞닿은 같은 지형 변마다 별 1개, 특별 타일은 2개입니다. 배치하는 타일의 배수만 적용합니다.
특별 타일은 스테이지 2부터 매 5번째 타일입니다. 별 목표는 ceil(덱 크기 × 1.5)입니다.
스테이지 3부터 숲 5타일 연결도 필요합니다. 양쪽 숲 변이 맞닿은 타일 그래프의 최대 연결 요소이며 시작 타일도 포함합니다.
별 목표, 덱 크기 min(14 + 스테이지 × 2, 30), 특별 타일 빈도 및 두 지형 형태 60:40은 실험값이며 플레이 기반 검증이 필요합니다.
시드 기반 덱은 두 지형 약 70%, 단일 지형 약 25%, 세 지형 약 5%이며, 두 지형은 4:2와 3:3 형태를 모두 사용합니다. 스테이지별 구성 수를 최대 나머지 방식으로 배분하고 순서를 섞습니다. 동률은 두 지형 → 한 지형 → 세 지형 순입니다.

## 저장
점수에서 별로 단위가 바뀌어 버전 3과 hexhaven-save-v3 키를 사용합니다. 기존 hexhaven-save는 보존하지만 자동 변환하지 않습니다. 이번 정합성 수정에서는 형식과 키를 변경하지 않고 기존 v3 덱·회전·별·목표·이력을 그대로 복원합니다.

## 검증
Node.js 24에서 npm test 실행. 외부 패키지는 필요 없습니다. GitHub Actions에서도 실행합니다.
- test/engine.test.js: 6방향 별, 특별 타일, 연결/순환/분리, 복합 목표, 배치/승패/되돌리기, 회전, 덱 결정성, 저장 왕복
- test/renderer.test.js: 실제 그리기 경로와 여섯 축 방향, pointy-top 꼭짓점 검증
- test/ui.test.js: DOM/Canvas 대역으로 탭, 회전, 배치, 되돌리기, 드래그 취소, 보드 이동, 도움말, 재시작

실제 iPhone Safari 검증은 미완료입니다. 환경에 브라우저 바이너리가 없어 자동 브라우저 테스트를 실행하지 못했습니다.
기기에서 안전 영역, 주소창 크기 변화, 탭/드래그, 두 번째 손가락 무시, 제스처 취소와 별 미리보기를 확인해야 합니다.
