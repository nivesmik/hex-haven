# 지형 완성 보너스 — 미승인 설계안

v0.8에는 구현하지 않는다. 기본은 v0.7의 일반 타일 일치 변당 1별 / 특별 타일 2별이다.
그래픽 변경과 보상 변경을 동시에 평가하지 않도록 UI 토글이나 숨겨진 추가 점수도 넣지 않는다.

향후 별도 실험의 제안:
- ruleset: `terrain-completion-v1` 같은 별도 버전과 저장 키로 분리한다. 기본값은 off이며 활성화는 승인 후에만 한다.
- 후보 완성 정의: 실제 같은 지형 변으로 연결된 요소의 해당 지형 변이 모두 맞닿아 열린 변이 없는 상태.
  최소 타일 수와 대상 지형, 지급량은 별도 플레이 실험으로 정한다. 생태 목표와 별개로 취급한다.
- 선택할 비교군: 기존 특별 타일 보상 유지군 / 특별 타일 없이 완성 보너스를 사용하는 군. 둘을 자동으로 합산하지 않는다.
- 중복 방지: 타일 ID와 지형으로 요소의 정체성을 기록하고, 이미 보상한 요소가 합쳐지거나 재로드돼도 같은 사건에 재지급하지 않는다.
- undo: 당시 보상·완성 이력도 함께 복원해 점수와 보드가 일치해야 한다. 단순히 발견 안내의 seen을 보상 원장으로 쓰지 않는다.
- 검증 항목: 닫힘/열림, 회전, 요소 병합, undo/redo, 재시작, 저장/복원, 기존 별과 중복 지급, 동일 시드 비교.
- 위험: 열린 변을 닫기 어려운 덱, 발견/지형 완성의 혼동, 보상 시점의 예측 가능성. 승인 전 정의·수치·이전 저장 처리부터 합의한다.
