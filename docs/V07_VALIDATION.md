- `npm test`, src/test/test-support/scripts JavaScript 문법 검사 및 `git diff --check`를 실행한다.

## 저장과 사건 의미
- 일반 v3 키 hexhaven-save-v3는 변경하지 않는다. 실험 키는 hexhaven-experiment-v07, 화면 선택은 hexhaven-view-v07이다.
- 실험은 v3에 experiment.version=1, ecosystem.seen, metrics를 추가하는 별도 네임스페이스다. 기존 일반 데이터의 마이그레이션은 필요 없다.
- 실제 생태 진행은 현재 보드에서 계산한다. undo 시 진행·Pass가 취소되지만 seen은 시도 동안 유지해 재안내를 막는다. 재시작은 seen을 비운다.
- 재시작·undo 카운터는 세션에 누적하고 모드/시드로 새 실험을 시작하면 초기화한다. 결과에 평가 등급과 보상은 없다.
- 로드·재시작은 저장된 덱과 목표를 보존한다. 알 수 없는 실험 버전은 거부하며 일반 데이터는 건드리지 않는다.
