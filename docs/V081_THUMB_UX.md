# v0.8.1-test.1 · 승인된 A안 엄지 조작

사용자가 디자인 목업 A안과 입력 규칙을 승인했다. 이 문서가 기존 v0.8 롱프레스/재탭 확정/배경 취소 설명을 대체한다. 이전 문서는 변경 이력이다.

- 빈 칸 탭: 선택. 다른 빈 칸 탭: 방향을 유지한 이동/예측/자동 구도. 같은 미리보기/배경 탭은 유지한다.
- 미리보기 하단 패널은 즉시 드래그 회전. 거리 32 CSS px당 60도, 역방향 8px 여유(실험값). 대기 시간 없음. 회전/점수 예측은 드래프트만 갱신한다.
- 하단 체크만 배치, X만 취소. 자동 배치 없음. 일반 undo 없음. PC 버튼/마우스 및 2D 보조 보기의 버튼은 유지한다.
- 패널에서 시작하면 pointer capture로 영역 밖에서도 회전만 지속. 확인 버튼 위로 드래그 종료해도 배치하지 않는다. 취소/blur/메뉴/방향 전환은 마지막 유효 회전 유지.
- 두 번째 손가락이 하단 입력을 중단하면 모두 뗄 때까지 입력 잠금. 보드로 핀치/회전을 넘기지 않는다. 보드에서 시작하는 팬·핀치·놓인 타일/배경 더블탭 홀드는 기존대로.
- 버튼은 최소 44×44px, 드래그와 버튼 행은 분리. 버튼 이동 8px 초과/외부 종료/멀티터치/취소 시 실행 안 함. 키보드와 보조기술 click은 별도 지원.
- iPhone은 하단 전체 폭, iPad 세로는 하단 중앙, 가로는 오른쪽. Safe Area+12px. 좁은 가로 화면은 카메라 사용 영역을 패널 왼쪽으로 제한한다.
- 최초 회전 성공까지 화살표가 최대 2번 움직이며, 성공 후 짧은 안내. reduced-motion은 애니메이션 없음.

## HUD / 결과 / 타일
상단 목표·남은 타일·성공 조건을 표시하고 중앙 Pass/Fail 카드에 실제 진행 수치를 보여준다. 일반 스테이지 목표와 Living River 목표를 구분한다. 수달/점수/생태/덱/v3 저장 규칙은 변경하지 않는다. 별은 점수 단위이며 결과 등급을 추가하지 않는다.
공유 육각형 변은 한 번만 렌더링한다. 평소 opacity .22, 전략 .4부터 적용. 특별 타일의 중심 별/꼭짓점 표식, 선택 시 일치 면의 실선/점과 불일치 면의 점선을 사용한다. 새 특수면 규칙이나 빈 타일 유리 표현은 없다.

## 버전 / 저장 / 운영
현재 테스트 버전은 v0.8.1-test.1이며 실제 배포 시 source SHA를 제목/메뉴/preview.json에 기록한다. 기존 current/ 저장 접두사를 유지해 확정 진행을 이어받는다. 프리뷰에는 빌드된 정적 파일만 배포하고 실제 개발은 nivesmik/hex-haven에서 관리한다. main 및 PR #3은 변경하지 않으며 PR #4를 갱신한다.

## 검증
Node의 기존 엔진/저장 테스트 + thumb 거리/반전 테스트. `scripts/test-integrated-v08.py`는 새 `test-thumb-v081.py` 실행 진입점이다. Chromium은 실제 CDP touch, Linux WebKit은 native tap + mouse pointer drag를 사용한다. old test-mobile-v08.py / test-browser-v08.py / test-webkit-v08.py는 이전 입력 정책의 기록으로 현재 CI 대상에서 교체했다. 팬/수달 검사는 유지한다.
요청 16개 시나리오를 새 통합 검사에 반영한다. 실제 iPhone/iPad Safari와 Android 물리 기기, 발열/주소창 변화는 미검증이다. 소프트웨어 GPU 결과를 실기기 성능으로 주장하지 않는다.
