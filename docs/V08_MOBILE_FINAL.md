# v0.8 모바일 조작 최종 패치

## 구현
- 모바일 한 손가락 짧은 탭: 빈 타일 선택. 이동이 먼저 8px을 넘으면 팬으로 확정하고 롱프레스 타이머를 취소한다.
- 배치 가능한 빈 타일에서 400ms 롱프레스: 좌표를 고정하고 타일 회전 모드로 진입한다. 36px마다 한 변씩 회전하며 방향 반전에는 8px 히스테리시스를 둔다.
- 손을 떼도 배치하지 않는다. 회전 중에는 확정/취소를 숨기고, 종료 후 선택 타일 근처에 46px 터치 영역과 20px 간격의 버튼을 표시한다.
- 버튼은 화면/HUD/하단 독/오른쪽 도구 영역을 피해 화면 안으로 제한하고 카메라 이동 시 재배치한다.
- 선택/회전은 draftRotation과 selected만 변경한다. 엔진의 rotation/board/deck/score/생태계는 확정 시에만 변경한다. 취소는 원래 값을 보존한다.
- 두 번째 손가락 또는 pointercancel은 회전 선택을 취소한다. 이후 멀티터치는 기존 핀치로 처리하며 자동 배치는 없다.
- 모바일 상시 회전/확정 버튼은 숨긴다. 확대/축소/중심 복귀와 PC 좌클릭 회전·우클릭 팬·회전 버튼은 유지한다.
- 카메라 보조 회전 제안: 두 손가락 비틀기. 수평 두 손가락 이동은 기존 팬과 충돌하므로 채택하지 않는다. 이번에는 새 보조 제스처를 적용하지 않으며 PC의 360도 회전은 유지한다.
- v0.8 3D의 중간 생태 이벤트 팝업은 제거한다. 새 수달 발견만 '새로운 동물 발견! 수달이 강가에 나타났어요.'로 표시하고 3초 후 닫는다. X로 즉시 닫을 수 있다.
- 도감 자료는 persisted ecosystem.seen에서 파생한 version=1 animals 배열이다. 별도 보상/발견 판정/중복 원장을 만들지 않는다. undo/재로드 중복 방지도 기존 seen을 그대로 사용한다.
- 이전 요청의 화면 기준 PC 팬과 돌 위에 앉은 수달 수정도 포함한다.

## 검증과 한계
- 기존 35 + 팬/수달 3 + 모바일 상태/도감 2 = Node 자동 테스트 40개.
- Chromium touch event를 실제로 보내 탭, 450ms 대기 후 좌우 회전, 떨림, 손 떼기, 확정/취소, 이동 우선 판정, 멀티터치/취소, 핀치, 알림 X와 3초 종료를 확인한다.
- 기존 PC/모바일 WebGL 배치·회전·undo·저장·클리어와 PC 카메라 각도별 팬 검증도 실행한다.
- 모바일 화면: /tmp/v08-mobile-rotation.png (실행 스크립트가 생성). 전후 수달 이미지는 V08_PAN_OTTER.md 참고.
- 실제 iPhone Safari는 미검증이다. 브라우저 터치 에뮬레이션은 실제 손가락·열·주소창·화면 안전 영역 검증을 대신하지 않는다.
- 2D fallback은 기존 조작 UI를 보존한다. 이 새 롱프레스 UX는 3D 경로에 적용한다.
- 긴 설명/열린 설정으로 화면이 작은 경우 버튼을 타일 바로 옆보다 안전한 화면 위치로 이동한다.
