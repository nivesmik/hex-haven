# v0.8 모바일 직접 조작 실험

이번 패치는 그래픽·퍼즐/생태 규칙을 보존하고 입력·카메라·되돌리기 노출 정책만 바꾼다. 대상은 PR #4 개발 브랜치다. main과 PR #3은 수정하지 않는다.

## 실제 동작

- **모바일**: 빈 칸 짧은 탭 → 전체 3D 미리보기와 약 260ms 자동 구도 이동. 같은 칸을 짧게 다시 탭하면 배치, 바깥 게임판을 짧게 탭하면 취소한다. 다른 빈 칸으로 직접 이동하지 않는다. HUD/메뉴 이벤트는 보드에 전달하지 않는다.
- 약 400ms 롱프레스 후 좌우 36px마다 60도 회전한다. 반대 방향 전환에는 추가 8px 히스테리시스가 있다. 임시 회전/좌표는 고정하며 손을 떼어도 배치하지 않는다.
- 먼저 8px 이동하면 팬으로 잠그고, 두 손가락은 핀치/팬이다. 회전 도중 두 번째 손가락이나 pointercancel이 들어오면 안전하게 미리보기를 취소한다. 현재 선택한 칸이 있는 동안 다른 칸의 롱프레스는 새 선택으로 이동하지 않는다.
- 모바일 확정·취소·상시 회전 버튼은 숨긴다. 줌/중심 복귀와 PC 좌클릭 orbit, 우클릭/Shift 팬, 회전/배치 버튼은 유지한다. 카메라 회전 보조 제스처나 버튼을 추가하지 않았다.
- 일반 플레이의 undo 버튼과 핸들러는 막고 `?testUndo=1`에서만 복구/실험용으로 허용한다. 엔진 undo와 저장 이력은 유지한다. 2D fallback도 같은 undo 정책을 쓴다. 2D 조작 자체는 기존 버튼 방식이다.
- 수달만 ‘새로운 동물 발견! 수달이 강가에 나타났어요.’를 3초 표시하고 X로 닫는다. 중간 생태 팝업과 발견 보상은 없다.

## 카메라와 입력의 분리

실제 HUD 아래부터 하단 미리보기/예상 별 위까지를 플레이 영역으로 계산하며 오른쪽 도구와 좌우 안전 영역을 피한다. 선택 타일 + 육각형 이웃 6개의 지면/낮은 식생 범위를 현재 투시 카메라로 투영한다. 선택 지점을 영역 중심에 놓았을 때 범위가 넘치는 경우에만 최소한으로 거리를 늘린다. 현재 거리로 충분하면 줌을 유지하고 시점/방위각은 바꾸지 않는다. 화면 비율별로 계산하며 거리 최대 42의 기존 제한을 유지한다.

260ms smoothstep 보간을 사용한다. 새 pointerdown, 수동 줌, 중심 복귀, resize, 취소/확정, 화면 이탈은 애니메이션을 중단한다. 따라서 누른 뒤 카메라가 계속 움직여 롱프레스 대상이 달라지지 않는다. 대상은 pointerdown 시의 보드 평면 Raycaster 좌표이며 엔진 판정은 그대로다. 동작 줄이기 설정은 즉시 이동한다. 극단적으로 작은 분할 화면이나 열린 설정창은 7칸 전체 표시를 보장하지 못한다.

## 저장·복구와 우회 점검

저장 스키마, 시드, 덱, 점수, 생태 조건은 그대로다. 미리보기/드래프트 회전은 저장하지 않고 확정된 한 스냅샷만 덮어쓴다. 새로고침/재접속/2D 전환으로 직전 배치를 되돌리지 않는다. 다른 탭의 저장 이벤트 및 BFCache 복귀에서 최신 저장을 읽고, 확정 직전에도 현재 저장과 일치하는지 검사해 오래된 선택의 덮어쓰기를 막는다. 진행 중 v0.7 가져오기는 일반 UI에서 비활성화한다.

새 실험·난이도 변경·명시적인 재시작은 새 시도를 시작한다. `testUndo=1`은 내부 테스트/복구 수단이며 보안 경계가 아니다. 개발자 도구로 localStorage를 수정하거나 외부의 옛 저장을 주입하는 것까지 막지 않는다. 서버 없는 실험 버전에서 조작 방지나 경쟁 공정성을 보장하지 않는다. 동시 탭의 완전한 트랜잭션 잠금도 아니다.

## 되돌리기 제거: 난이도 및 UX 검토

- **초반 실패**: 첫 스테이지도 별 목표 미달로 실패할 수 있다. 되돌리기 없이 학습 비용이 커지므로 첫 진입 안내/편안함의 실패율을 실기기로 관찰할 필요가 있다. 이번에는 목표·덱·확률을 바꾸지 않았다.
- **오조작과 판단 실패**: 첫 탭은 무상 미리보기, 재터치만 확정, 바깥 탭은 무상 취소다. 회전 종료/팬/핀치가 확정되지 않으므로 오조작은 줄이되 확정된 전략 선택의 결과는 남긴다. 자동 구도 이동 때문에 확정 위치가 달라 보이는지 실기기 피드백이 필요하다.
- **도달 불가능 상태**: 남은 타일이 부족해 물/숲 크기나 별 목표를 더 이상 충족할 수 없으면 회복 불가다. 엔진은 모든 상태의 해답 탐색이나 조기 Fail 판정을 하지 않고 덱 소진 시 Fail로 처리한다. 따라서 불리한 상태에서도 남은 타일을 플레이할 수 있다.
- **무작위 공급**: 난이도+시드는 결정적이고 자원 부족 덱을 재추첨하지만 이것은 해답 보장이 아니다. 기존 15개 조합 중 13개에서 찾은 Pass 경로는 재현되며 기본/도전 seed=1271은 기존 제한 탐색에서 미검증이다. undo 제거가 해결 불가 덱을 새로 만들었다고 단정하지 않으며, 실수 이후의 회복 가능성은 낮아진다. 다음 타일 공급/목표/점수는 변경하지 않았다.
- **향후 모드 차등(제안, 미구현)**: Comfort는 제한 없는/제한된 undo, Standard는 무상 미리보기+undo 없음, Challenge는 undo 없음으로 비교할 수 있다. 현재는 세 모드 모두 일반 UI에서 undo 없음이다. 실수율·재시작률·완료율을 먼저 수집해야 하며 보상 차등은 제안하지 않는다.

## 배포와 검증

`tools/build-pages-preview.py --sha <커밋> --output <경로>`로 모든 런타임 모듈·Three.js를 복사하고 상대 import와 CSS URL에 커밋 버전을 붙인다. 별도 경로 `hex-haven-preview/pr-4-puzzle/` 및 저장 접두사 `hexhaven-preview:pr-4-puzzle:`를 사용한다. 기존 공식/v0.7/이전 v0.8 미리보기 저장은 읽거나 덮어쓰지 않는다. 명시적 PR #3 저장 복사만 초기 상태에서 허용한다. 기본은 Standard, seed 202607이고 새로고침은 진행을 유지한다. 자동 초기화 URL은 제공하지 않는다.

`preview.json`은 소스 SHA와 각 런타임 파일 SHA-256을 제공하며 상단 버전에도 짧은 SHA가 있다. 공개 HTTPS 응답·각 파일 해시·브라우저 WebGL/터치/저장 재접속을 확인한 뒤 URL을 보고한다.

자동 테스트 44개, Chromium PC 1280×800/모바일 390×844·320×568, 직접 터치 390×844·844×390·768×1024·1024×768·320×568, Linux WebKit 390×844·768×1024·1024×768에서 통과했다. WebKit은 네이티브 탭/취소/확정/저장 복원 검사이며 롱프레스/핀치의 실제 터치 입력은 Chromium에서 검증했다.

자동/브라우저 결과와 스크린샷은 `docs/V08_PUZZLE_RESULTS.json`, `docs/screenshots/puzzle-*.png`를 참조한다. Chromium은 소프트웨어 GPU와 터치 에뮬레이션이며 모바일 하드웨어 성능 측정이 아니다. 실제 iPhone/iPad Safari, Android 기기에서 안전 영역·브라우저 주소창 높이 변경·손떨림/회전 감도·장시간 발열·백그라운드 복귀를 추가 확인해야 한다.
